# QuickQr privacy policy

_Last updated: 21 November 2026_

QuickQr is built to work **offline and privately**. It has no ads and no analytics or tracking SDKs, and you don't need an account.

## Data stored on your device
- **History.** The codes you create and scan, plus any notes and tags you add, are stored in a local database. You can delete single entries or clear all of them in the app at any time.
- **Settings, brand kits and purchase status.** These are stored locally. Purchase status is kept in the platform's secure storage.
- QuickQr never uploads this data anywhere.

## Permissions
- **Camera.** Used only to scan codes. Frames are processed on the device and are never saved or transmitted.
- **Photos and files.** Used only when you pick an image to scan or save a generated code.
- **Biometrics.** Used only for the optional app lock. The operating system does the authentication; QuickQr never sees your biometric data.
- **Wi-Fi.** Used only when you ask QuickQr to join a network from a scanned Wi-Fi code.

## Network access
- **Opening links.** Links you choose to open go to your system browser.
- **Update checks.** Builds installed from GitHub may ask GitHub's public releases API whether a newer version exists. No personal data is sent. Store builds don't do this.
- **Purchases.** In-app purchases are handled entirely by Google Play, the Apple App Store or the Microsoft Store.
